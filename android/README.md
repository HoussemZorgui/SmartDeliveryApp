# Android Project Setup

This folder is reserved for the Android application. Since this environment cannot run the Android Studio Project Wizard, please follow these steps:

1.  Open **Android Studio**.
2.  Select **New Project**.
3.  Choose **Phone & Tablet** -> **Empty Views Activity** (or **Basic Activity**).
4.  Configure the project:
    *   **Name**: Smart Delivery App
    *   **Package name**: com.example.smartdeliveryapp (or your preferred package)
    *   **Save location**: Point to this `.../SmartDeliveryApp/android` directory.
    *   **Language**: Kotlin
    *   **Build configuration language**: Kotlin DSL (build.gradle.kts)
5.  Click **Finish**.

Once initialized, we can proceed with adding dependencies for Maps, Socket.io, etc.
